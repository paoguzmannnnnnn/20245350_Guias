Acerca de la Materia

Descripción del Curso

Desarrollo Web I es una materia fundamental del ciclo 3 en la ESEN que introduce a los estudiantes en los conceptos básicos del desarrollo web front-end junto con JavaScript

Contenido del curso

  • Introduccion al HTML
  • Introduccion a las hojas de estilo en cascada (CSS)
  • Maquetacion de sitios web
  • Frameworks de diseño web responsivo
  • Introducción a Javascript
  • El modelo de objetos de documento (DOM) y javascript asincrono

FODA sobre el Desempeño

Fortalezas

He mejorado mis habilidades en HTML, CSS y JavaScript, logrando crear páginas web funcionales básicas y con un mejor diseño. Desarrollé una mayor capacidad para resolver errores en el código y entender cómo funciona la estructura de un sitio web. También, aprendí a usar GitHub lo que facilitó el trabajo en equipo y ser más estructurada con mis documentos.

Oportunidades

El conocimiento adquirido me servirá para crear portafolios personales o prototipos de proyectos en el futuro. Puedo aplicar lo aprendido en otros cursos de programación o diseño de interfaces (UX/UI) como lo estramos haciendo en otras materias, por ejemplo Requerimiento y Prototipado. Desarrollar sitios web puede convertirse en una habilidad profesional útil para trabajos o emprendimientos y es algo que me interesa bastante.

Debilidades

Aún necesito fortalecer mi comprensión de JavaScript pero con la práctica se puede mejorar. Me cuesta un poco el diseño responsivo y la optimización para diferentes dispositivos. A veces me falta confianza al momento de aplicar conceptos nuevos sin ejemplos previos.

Amenazas

La falta de tiempo por otras materias o responsabilidades afectó mi ritmo de práctica. De ahí, a futuro, los cambios rápidos en tecnologías web pueden hacer que sea necesario actualizarse constantemente, y si no se tiene en cuenta, puede ser una amenaza bastante grande.
